Программа реализована на языке С++ в виде консольного приложения и состоит из двух основных классов: Compiler и Interpreter. 
Класс Compiler выполняет лексический, синтаксический и семантический анализ исходной программы, формируя синтаксическое дерево. 
Класс Interpreter осуществляет выполнение программы путём обхода построенного дерева.

Лексический анализатор (метод lex_analizator()) выполняет посимвольный разбор исходного текста и формирует последовательность токенов. 
Каждому токену присваивается тип (ключевое слово – 3, идентификатор – 1, число – 2, разделитель – 4) и 
индекс в соответствующей таблице (perem – для идентификаторов, znach – для чисел). Результатом работы является вектор posled, содержащий последовательность токенов программы.
Синтаксический анализатор (метод syntax_analysis()) получает последовательность токенов и 
с помощью набора рекурсивных процедур (parseStatement(), parseExpression(), parseTerm(), parseFactor() и др.), реализующих 
метод рекурсивного спуска, проверяет соответствие программы грамматике языка. В процессе разбора синтаксический анализатор 
строит синтаксическое дерево через класс ASTNode, используя стек контекстов (nodeStack) для управления иерархией узлов.
Семантический анализатор реализован в виде отдельных проверок, выполняемых параллельно с синтаксическим разбором. Его функции:
• контроль объявления переменных перед использованием;
• запрет повторного объявления переменной в одной области видимости;
• проверка инициализации переменной перед использованием в выражении.
Для хранения семантической информации используется вектор vector<pair<int, int>> obnova, где для каждой переменной 
хранятся два состояния: уровень блока, в котором она объявлена (0 –не объявлена, 1 –глобальная область, 2 и более — вложенные блоки), 
и признак инициализации (0 – не инициализирована, 1 – инициализирована).
Переменная blok_perem отслеживает текущий уровень вложенности блоков. При входе в блок значение blok_perem увеличивается, 
при выходе — все переменные, объявленные в этом блоке, удаляются из таблицы.
Результатом совместной работы синтаксического и семантического анализаторов является синтаксическое дерево — иерархическая структура, 
в узлах которой хранится информация о синтаксических конструкциях программы.
Интерпретатор (класс Interpreter) получает корень синтаксического дерева и выполняет программу путём рекурсивного обхода. Метод exec() обрабатывает инструкции 
(объявление переменных, присваивание, условный оператор, ввод-вывод), а метод eval() вычисляет арифметические и логические выражения. Результаты выполнения выводятся в консоль.
